# Phishing Awareness Training

An interactive web-based phishing awareness training module developed as part of the **CodeAlpha Cyber Security Internship — Task 2**.

## Project Objective

The purpose of this project is to educate users about phishing attacks and help them identify suspicious emails, fake websites, and common social engineering techniques.

The module also provides practical security tips and includes an interactive quiz to test phishing awareness.

## Topics Covered

- What phishing is
- Email phishing
- Spear phishing
- Smishing
- Vishing
- Recognizing phishing emails
- Identifying fake websites
- Social engineering tactics
- Best practices for avoiding phishing
- Real-world style phishing examples
- Interactive phishing awareness quiz

## Features

- Responsive web-based training module
- Phishing email example
- Fake website warning signs
- Social engineering explanations
- Real-world style phishing scenarios
- Security best practices
- Interactive multiple-choice quiz
- Automatic quiz scoring
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

No external framework is required.
