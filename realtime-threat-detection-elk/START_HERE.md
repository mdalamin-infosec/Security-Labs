# Start here

Follow the [README](README.md) for fresh-clone setup, the installed offline
Python CLI, and the optional Linux Compose stack. All commands assume this
project directory. Source is in `src/threatwatch/`; the authoritative signatures
are packaged in `src/threatwatch/data/local.rules`.

Read [validation](docs/VALIDATION.md) before describing results. The live stack,
actual-engine replay and operational performance remain personal TODOs.
Keep generated events, reports, captures and real secrets out of Git.
