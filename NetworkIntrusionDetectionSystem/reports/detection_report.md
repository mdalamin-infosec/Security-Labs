# Network Intrusion Detection Report

## Project

CodeAlpha Cyber Security Internship

Task 4 — Network Intrusion Detection System

## Objective

The purpose of this project is to configure and test a network-based intrusion detection system using Suricata in an isolated VirtualBox lab environment.

The project focuses on:

- Monitoring network traffic
- Detecting suspicious activity
- Generating alerts
- Creating custom Suricata rules
- Demonstrating continuous monitoring
- Implementing a basic response mechanism
